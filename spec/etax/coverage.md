# e-Tax の様式の対応表

domble は会計ソフトで、中心は帳簿（仕訳 → 元帳 → 試算表 → 決算書）です。この表が見るのは、その出口の **e-Tax に出す申告データ（.xtx）** だけです。
帳簿の側は、法令の要件（青色申告の帳簿・電子帳簿保存法）と市販の会計ソフトでふつうにできることを比べる相手にしています（`spec/audit/`）。

- 元にしたもの：国税庁の e-Tax 仕様書の手続の XSD（このフォルダ）。様式の一覧は次で出せます。新しい版を入れたら、この表と見比べます
  ```
  python3 -I scripts/etax_procedure_forms.py shotoku/RKO0010-250.xsd
  ```
- e-Tax 仕様書の「手続内帳票対応表」では、申告書も含めてどの様式も「任意」です。**出さなければならない書類かどうかは、法令と国税庁の手引きで決まります**（備考に書いた）
- 対象の利用者：事業所得のある個人事業主（青色・白色）。不動産所得は A3 で対象に入れることにしている
- 版：所得税は令和7年分（RKO0010・25.0.1）、消費税は 23.2.0（RSH0010・RSH0030）。令和8年分の所得税の版はまだ出ていない（出たら様式の変わったところを確かめる）
- 調べた日：2026-10-29

記号
- domble：○ = 書き出せる、△ = 一部の欄だけ、× = まだ、— = 対象にしない
- 優先度：**高** = 対象の利用者に多い場合に要り、無いと申告を出しきれない／中 = 使う人の多い控除の明細や、あると手間が減るもの／低 = 限られた人だけ

### 対象にしない様式
次の所得・人・特例の様式は、今の対象の外です（増やすなら「対象にするか決めるもの」で決める）。

- 株式・先物の譲渡と繰越損失：KOA050・KOA070・KOA090・KOB550・KOC080〜KOC110・KOC250
- 土地・建物などの譲渡、居住用財産の譲渡損失、相続財産の取得費：KOC010〜KOC070・KOC130〜KOC160・KOC210・KOC220・KOC240
- 山林所得：KOD010・KOD020
- 準確定申告（亡くなった人の申告）：KOA060
- 非居住者・国外転出：KOB245・KOB405・KOB540・KOC180・KOC190・KOC200・KOC230
- 医師・歯科医師用の付表：KOA140・KOA250
- 配当・外国税額・年金などの特殊な計算：KOB100・KOB240・KOB890・KOB900・KOB975
- 給与所得者の特定支出：KOB070
- 特定の業種・地域・災害の準備金や特別控除：KOB040・KOB090・KOB210〜KOB230・KOB300・KOB330・KOB440・KOB690・KOB750〜KOB840・KOB940〜KOB998 の残り
- 住宅の耐震改修・認定住宅等の特別控除：KOB131・KOB827・KOB835（住宅借入金等特別控除 KOB130 を作るときに、一緒に考える）

## 優先度の高いもの（まとめ）
1. 医療費控除の明細書：明細の入力（医療を受けた人・支払先・区分・金額、医療費通知の合計）と KOB560。明細書が無いことは、書き出すときに知らせている
2. 消費税の還付申告に関する明細書：B6
3. 青色申告決算書（一般用）の書いていない欄：D-11〜D-13

収支内訳書（一般用）は 2026-10-29 に書き出せるようにした（A4）。所得税の第四表（損失申告）も 2026-10-29 に書き出せるようにした（A5）。

申告書の「出しきれない」を減らす順で並べています。帳簿の側の残り（A7・B3〜B5 など）とあわせて、README の「足りていないところ」で順番を決めます。
