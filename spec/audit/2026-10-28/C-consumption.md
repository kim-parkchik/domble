## 指摘

### C-01 免税事業者から課税事業者になった年の棚卸資産の調整（付表2-3 ⑯）を入れられない
- 判定：未対応
- 重さ：A（数字が違う）
- 制度の根拠：
  - 消法36①。課税事業者になった日の前日に持っていた棚卸資産のうち、免税事業者の期間に仕入れたものの消費税額を、課税仕入れ等の税額に加える。
  - 「令和7年分 消費税及び地方消費税の確定申告の手引き 個人事業者用（一般用）」step.12 と設例「甲野商店」。期首商品棚卸高 1,741,000円 × 7.8/110 = 123,452円 を ⑯B に入れる。https://www.nta.go.jp/publication/pamph/shohi_kojin/r06/01.htm
  - タックスアンサー No.6491。https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6491.htm
  - 令和8年分も同じ。
- コードの根拠：
  - src/lib/taxReturn.ts:13：未対応として列挙している。
  - src/lib/taxReturn.ts:322：⑰ は ⑩＋⑫ だけで、⑭⑮⑯ が無い。
  - README.md:373
- 内容：
  - 令和7年分の公式の設例（甲野商店。令和6年は免税、令和5年分の課税売上高 19,951,456円 で令和7年分から課税、本則課税）を、そのままの数字で domble に通した（work-C/kono2025.ts）。
  - ①・⑦・⑧（98.34%）・⑨・⑩（504,746 / 545,290）・⑫（93,600）・付表1-3 ②（1,434,529）は国税庁と一致する。
  - ⑯ 123,452円 を入れる場所が無いので、⑰ が 1,143,636円 になる（国税庁は 1,267,088円）。
  - その結果、第一表 ⑨ は 290,800円（国税庁 167,400円）、地方消費税は 82,000円（同 47,200円）。納める額が 157,600円 多くなる。
  - 基準期間の課税売上高が1,000万円を超えて課税事業者になった人は、2割特例を使えない。だから在庫のある小売・飲食で本則課税を選ぶ人は、まさにこの例に当たる。
  - 年の途中で登録した人は、登録日の前日の棚卸資産で調整する。
  - 課税事業者から免税事業者になる年の減算（同じ ⑯）も入れられない。
- 直し方の案：
  - 年度ごとに「⑯ 調整額（加算・減算、税率ごと）」を手で入れる欄（または棚卸資産の取得価額と税率から計算）を持ち、⑰・xtx の DTE に入れる。
  - 課税事業者になった年の本則課税で、期首（課税事業者になった日）の棚卸高があれば、確認の一覧で知らせる。

### C-02 還付申告に「消費税の還付申告に関する明細書（個人事業者用）」を付けられず、知らせもしない
- 判定：未対応
- 重さ：B（法令の要件を満たさない）
- 制度の根拠：
  - 消費税法施行規則22③。控除不足還付税額がある申告書には、明細書を添付する。
  - 個人事業者用（一般用）手引き。「還付申告の方（申告書第一表8欄に控除不足還付税額がある方）は…還付申告に関する明細書（個人事業者用）を必ず提出してください」とある。
  - タックスアンサー No.6615。https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6615.htm
  - 記載要領。https://www.nta.go.jp/taxes/tetsuzuki/shinsei/shinkoku/shohi/07/kojin_youryou.pdf
- コードの根拠：
  - src/lib/taxXtx.ts:211-216：書く様式は第一表・第二表と付表だけで、SHC025 は無い。
  - spec/etax/shohi/SHC025-002.xsd：手続 RSH0010-260 には含まれている。
  - 画面（src/features/reports/TaxReturnView.tsx）にも案内が無い。
- 内容：
  - 本則課税で ⑧ 控除不足還付税額が出ると、domble は還付先の口座つきの xtx を書き出す。
  - その xtx には明細書が無い。WEB版は読み込んだデータを直せないので、そのまま送ると添付漏れの申告になる。
  - 設備投資の年や、輸出の多い事業で起きる。
  - 例：課税売上 1,100,000・課税仕入 3,300,000 → ⑧ 156,000 の還付。src/lib/taxXtx.test.ts:196 の refundReturn の場合。
- 直し方の案：
  - ⑧ > 0 のときは、画面で明細書が要ることを知らせる。
  - 少なくとも明細書の項目を出す：還付の主な理由、主な課税資産の譲渡等、主な棚卸資産・固定資産の取得（税抜き100万円以上を上位5件。台帳と仕訳から候補）。
  - xtx に SHC025 を書く。

### C-04 業務用の固定資産の売却が、初期値のままだと課税売上から漏れる。家事と兼用する資産の取得は全額が課税仕入になる
- 判定：不完全
- 重さ：C（実務で困る。初期値のままだと数字が違い、知らせもない）
- 制度の根拠：
  - 消法2①八・28①：事業用資産の譲渡は課税資産の譲渡等。課税標準は帳簿価額ではなく譲渡対価。
  - 個人事業者用手引き（一般用・簡易課税用）の設例：配達用車両を 280,000円 で売却し、課税売上に含める（簡易課税では第4種）。
  - 家事と兼用する資産は、事業用の部分だけが課税仕入れ（消基通11-1-4）。
- コードの根拠：
  - src/lib/tax.ts:141-145：資産の科目の貸方は、初期値が対象外。
  - src/lib/taxSummary.ts:172-180：資産に売上の区分は出さない。
  - src/lib/depreciation.ts:53：台帳に disposed_on（売却・除却の日）がある。
  - README.md:384：売却の仕訳は自動で作らない。
- 内容：
  - 「普通預金 280,000 ／ 車両運搬具 200,000・事業主借 80,000」と入れると、どの行も対象外になり、課税売上に入らない（work-C/scenario2025.ts、konoDefaults.ts）。
  - 正しく入れるには、売却額の全体を課税売上にしなければならない。そのために次の2つの行に「課税売上 10%」を付けることになる：
    - 資産の科目の行（帳簿価額の部分）
    - 事業主借の行（差益の部分）
  - その場合、事業主借の行は「負債・資本の科目に対象外以外の税区分」の警告が出る。簡易課税では、事業主借の行は主な事業区分（例：第5種）になり、第4種にならない。
  - 固定資産台帳に売却日が入っていても、確認の一覧は何も言わない。
  - 本則課税で、家事と兼用する車（事業専用割合 70%）を 3,300,000円 で買うと、3,300,000円 全額が課税仕入になる（本来は 2,310,000円）。台帳の事業専用割合は減価償却費にしか効かない。
  - 甲野商店の一般用の設例では、車両の売却が漏れると付表1-3 ② は 1,414,717円 になる（国税庁 1,434,529円）。簡易課税用の設例では、⑨ が 227,200円 になる（国税庁 231,200円）。
- 直し方の案：
  - 台帳で売却日を入れたときに、譲渡対価を入れて売却の仕訳を作る。仕訳は、課税売上（第4種）の行を譲渡対価で1本立てる。
  - 少なくとも、売却日のある資産があるのに、その年の資産の科目に課税売上が無ければ確認の一覧で知らせる。
  - 本則課税で、事業専用割合が100%未満の資産を取得した明細は知らせる（または事業用の部分で分ける）。

### C-06 確認の一覧が、方式を選ぶ前提を確かめていない（2割特例の登録、簡易課税の届出・2年継続、高額特定資産）

    - 本則課税の年に取得した、1,000万円以上の資産の一覧（台帳と仕訳から）
  - 持ったものを使って、2年継続・3年の制限を確認の一覧で知らせる。
  - 登録日がその年の途中で、課税事業者になった日が空なら「念のため」で知らせる。

- 直し方の案：本則課税の付表2-3 に、㉓〜㉕ の手入力欄（加算・減算）を置き、㉖㉗ の計算に入れる。

### C-13 中間申告：仮決算の計算、中間申告書のデータ、振替継続希望

  - 振替納税を続ける希望を xtx に書かない。

### C-16 免税事業者の期間の売上に係る返還・貸倒れを区別しない
- 判定：未対応
- 重さ：D（あると良い）
- 制度の根拠：
  - 消法38・39。免税事業者だった期間の売上に係る対価の返還等・貸倒れは、税額控除の対象にならない。
  - 国税庁 質疑応答「免税期間の資産の譲渡に係る対価の返還等の取扱い」https://www.nta.go.jp/law/shitsugi/shohi/15/01.htm
- コードの根拠：
  - src/lib/taxReturn.ts:69-82：課税事業者の期間の明細は、もとの売上の時期を見ずに返還・貸倒れにする。
  - src/constants/tax.ts:88：貸倒金の初期値は貸倒れ 10%。
- 内容：
  - 令和7年4月に登録した人が、令和6年（免税）の売掛金を令和7年に貸倒れにすると、初期値のままでは貸倒れに係る税額 ⑥ が控除される。
- 直し方の案：課税事業者になった最初の年に、貸倒れ・売上の返還の明細があれば「もとの売上が課税事業者の期間か」を確認の一覧で知らせる。

## まとめ
- 重さ A：1件（C-01）。重さ B：1件（C-02）。C：8件（C-03〜C-10）。D：6件（C-11〜C-16）。
- 計算そのものは確か。令和7年分の個人事業者用の手引き（一般用・簡易課税用）の設例、書き方（一般用・簡易課税用）の設例、2割特例用手引きの設例と、端数まで一致した。ただし一般用の設例は、⑯ を除いて一致した。中間申告の回数・額・期限も正しい。

いちばん大事な3点：
1. **C-01（A）免税→課税の年の棚卸資産の調整（付表2-3 ⑯）が入れられない。**
   - 令和7年分の公式の設例（甲野商店）で、第一表 ⑨ が 290,800円 になる（国税庁 167,400円）。
   - 基準期間1,000万円超で課税事業者になった、在庫のある小売・飲食の人は2割特例を使えないので、本則課税で必ずこれに当たる。
   - ⑯ の入力欄（税率別、加算・減算）を足す。
2. **C-02（B）還付申告の「消費税の還付申告に関する明細書（個人事業者用）」を作らず、知らせもしない。**
   - 還付の xtx はそのまま送れる形で出るので、添付漏れの申告になる（規則22③）。
3. **C-03（C）令和7年分の xtx を書き出せない。**
   - 手元の CAB に令和7年分の手続 XSD（RSH0010-232・RSH0030-232、版 23.2.0）があり、様式は 26.0.0 と同じ。
   - domble の出力の版と課税期間を変えるだけで XSD に合うことを確かめた。年分 → 版の表を持てばすぐ直せる。
   - あわせて、初期値と確認の一覧の弱さ（C-04 固定資産の売却、C-05 雑収入・地代家賃・福利厚生費の初期値）を直すとよい。これらで公式の設例が 167,400円 → 259,100円 にずれても、確認の一覧は何も出さない。
