# F 一年分の続け通し（令和7年分・3人の例）

代表的な個人事業主3人について、令和7年（2025年）の一年分を domble で通した。帳簿付けから決算書・申告書の数字まで、domble の repo 関数（src/db/repo.ts）と計算（src/lib）を使い、国税庁の決まりで手計算した値と比べた。

- **スクリプト**：`spec/audit/scenarios/`（`sh spec/audit/scenarios/run_all.sh`）
  - `common.ts`（共通の部品）
  - `s1_designer.ts`・`s2_retail.ts`・`s3_restaurant.ts`（3人の例）
  - `s4_r7_rules.ts`（所得税の決まりを令和7年分と比べる）
  - `run_all.sh` でまとめて流せる。結果は `out_*.txt`、例3の銀行明細は `s3_bank_2025.csv` に残る
  - 各スクリプトの先頭に、何を確かめるかを書いてある
- **DB の作り方**：src/db/repo.test.ts の makeDb と同じにした（bun:sqlite のメモリ上・厳密モード・settings.fiscal_year = 2025・青色65万円）
- **画面のまね方**：画面がしている組み立てを、画面のコードと同じ呼び方でまねた。対応は次のとおり
  - 帳簿入力：CashBookPage.save の家事按分（入力のたびに）
  - 振替伝票：rowsToLines → splitLinesByHomeUse
  - 固定資産台帳：depreciationLines → saveDepreciationRun
  - 家事按分の年末の振替：yearEndRows → privateTaxSplit → saveHomeUseRunEntry
  - 明細の取り込み：guessColumns → parseStatement → addBankLines → guessLine・findBookDuplicate → registerBankLines
  - 決算書：statementLayout・monthlySales・payeeBreakdown・depreciationFor
  - 消費税：buildTaxBase → computeReturn・interimPlan・taxChecks
  - 所得税：computeIncomeTax
- **判定の付け方**：「一致／違う／出せない」の3つ
  - 所得税の画面（IncomeTaxPage）は 2026年より前を出さない。そのため所得税は `computeIncomeTax(…, 2025)` を直接呼んだ値を「domble の値」にした

## 出せた数字と手計算の比べ

### 先に結論

- **所得税以外はすべて一致した**：3人とも、帳簿 → 残高試算表 → 青色申告決算書の数字 → 消費税の申告書 → 翌年への繰越 → 翌年の中間申告の判定まで、手計算と1円も違わなかった
  - 消費税の申告書は3つの方式で確かめた：2割特例、簡易課税（2種類の事業）、本則課税（経過措置あり）
- **違ったのは所得税だけ**
  - 令和7年分は画面で出せない
  - 計算は令和8年分の決まり（基礎控除など）で固定されている
  - そのため3人とも税額が約8千円違う
- **出せないもの**
  - 令和7年分の消費税の e-Tax データ
  - 未払消費税の仕訳
  - 所得税・決算書の e-Tax データ
  - 銀行明細の1行を複数の科目に分けること

## まとめ

- **重さ A：3件**（F-1・F-2・F-4）
- **重さ B：1件**（F-3）
- 重さ C：7件（F-5〜F-11）、重さ D：3件（F-12〜F-14）
- 確かめた項目：205項目
  - 3人の例：191項目。数字は所得税以外すべて一致（違う・出せないは26項目で、所得税と、e-Tax データ・未払消費税の仕訳のような「出せない」もの）
  - 所得税の決まりの補足：14項目

**いちばん大事な3点**

1. **令和7年分の所得税は、画面で出せず、計算も令和8年分の決まりで固定されている（F-1・F-2）**
   - 3人とも、帳簿・決算書・消費税までは正しく通る。最後の所得税だけが、出せないか、出しても約8千円違う
   - 違いは、基礎控除・給与所得控除・扶養の所得要件・配偶者の区分・生命保険料の特例
   - 年分ごとの決まりの表にして year で引けば、帳簿の側を直さずに令和7年分まで閉じられる
2. **専従者の配偶者に配偶者控除が出てしまう（F-3）**
   - 専従者給与を経費にした例3で、妻を配偶者として入れると、止めも知らせもなく 38万円の控除が付く
   - 青色事業専従者を持つ事業ではよくある入力の誤りで、法令の要件どおりに防ぐ必要がある
3. **帳簿 → 決算書 → 消費税の申告書の数字は、3つの方式とも手計算と1円も違わなかった。足りないのは出口と決算の手間（F-5〜F-10）**
   - 令和7年分の e-Tax データ（消費税・所得税・決算書）が無い
   - 未払消費税・棚卸の振替・決算整理前後の試算表は手作業
   - 明細の1行を分けて仕訳にできない
   - 数字の正しさは確かめられたので、残るのはこれらを市販のソフト並みにする作業
