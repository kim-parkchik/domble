## 頼まれた調べもの
1. **国税庁の様式どおりの申告書・決算書の印刷**（D-07、`2026-11-04/D-income.md` の要望1）：税務署は書面の申告書・決算書を OCR で読むため、定型の様式で出す必要がある。国税庁は市販ソフト向けに OCR 帳票の仕様書を毎年出しており、メールで申し込む（所得税と個人の消費税を1通で頼め、2〜4営業日で届く）。用紙は A4 の普通紙・片面、カラーの OCR 帳票は白黒では読めない。今の domble の印刷（欄の番号つきの表）は写すための下書き。作るなら、仕様書を取り寄せ、xtx と同じ欄の値から位置を決めた PDF を年分ごとに作る（第一表・第二表 → 決算書の順）
2. **所得税で扱わない所得・控除の分類**（要望2）：扱うべき＝事業用の車両・機械を売ったときの譲渡所得（D-04）。あると良い＝住宅借入金等特別控除の2年目以後・一時所得・変動所得の平均課税・純損失の繰戻し還付・業務に係る雑所得の収支内訳書。作成コーナーや税理士に任せてよい＝配当・分離課税・雑損控除と災害減免・特定支出控除・外国税額控除。対象外＝山林所得・退職所得
3. **e-Taxソフト（WEB版）で所得税の xtx を読み込めるか**（要望3）：国税庁の案内（e-Tax よくある質問）では、民間ソフトの .xtx は WEB版の「作成済みデータの利用」で読み込んで送れる。README・操作説明書の書き方は合っている。手続ごとの制限は手順の PDF で要確認
4. **画面の自動テスト**（E-12、`2026-11-04/E-ops.md`）：Tauri 公式の WebDriver は macOS で使えない。本番の画面は WebKit なので、`.claude/preview` の模擬（Vite と bun:sqlite の模擬 DB）を Playwright の WebKit（ブラウザはおおよそ 100MB 前後）で動かす案を勧める。細かい入力の部品だけ happy-dom と Testing Library の bun test を足す。模擬の作りを git に入る場所へ移し、テスト用の帳簿は毎回 repo の関数で作る。最初のテストの候補：日付と貸借の確かめ、締めと締めを戻す、通常モードの削除、請求書の発行・訂正・入金・取消、読み取り専用、バックアップから戻す、明細の二重の取り込み、権限
